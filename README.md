> **Учебный проект по сегментации клиентской базы с использованием RFM- и ABC-анализа.**

---

## 📌 О проекте

Аптечная сеть располагает механизмом SMS-рассылок, однако бюджет на коммуникации необходимо использовать эффективно.

Цель проекта — **сегментировать клиентов по их покупательскому поведению и определить, какие маркетинговые предложения целесообразно направлять каждой группе клиентов.**

Основная идея исследования:

> Не имеет смысла предлагать одинаковую персональную скидку клиенту, который совершил одну покупку, и клиенту, который регулярно совершает покупки и формирует значительную часть выручки.

---

## 🎯 Цели исследования

- классифицировать клиентов по покупательскому поведению;
- выделить наиболее ценные клиентские сегменты;
- определить клиентов с риском ухода;
- выявить клиентов с единичными покупками;
- проверить выдвинутые гипотезы;
- сформировать рекомендации для персонализированных рассылок.

---

## 🔎 Гипотезы

### Гипотеза 1

Основная часть выручки формируется ограниченной группой наиболее активных клиентов.

**Для проверки:** ABC-анализ по выручке клиентов.

### Гипотеза 2

Клиенты отличаются по уровню вовлечённости: часть клиентов совершает только одну покупку и не возвращается.

**Для проверки:** анализ Frequency и распределения количества покупок.

### Гипотеза 3

Клиенты, которые давно не совершали покупок, имеют высокий риск ухода и требуют отдельных мероприятий по возврату.

**Для проверки:** анализ Recency.

---

# 📈 Методология

Для сегментации клиентов использован **RFM-анализ**.

| Метрика | Что показывает |
|---|---|
| **R — Recency** | Давность последней покупки |
| **F — Frequency** | Количество покупок |
| **M — Monetary** | Общая сумма покупок |

Для каждой метрики использована трёхуровневая оценка:

- `1` — хороший показатель;
- `2` — средний показатель;
- `3` — низкий показатель.

В результате формируется **27 возможных RFM-сегментов**.

---

## 🧹 Подготовка данных

Для идентификации клиента использовался **номер бонусной карты**.

В анализ включались покупки, для которых можно было достоверно определить клиента.

Покупки без идентифицируемой бонусной карты были исключены из клиентского RFM-анализа.

Основные поля исходной таблицы:

- `datetime` — дата и время транзакции;
- `shop` — аптека;
- `card` — номер бонусной карты;
- `summ` — сумма чека;
- `summ_with_disc` — сумма чека с учётом скидок и списаний бонусов;
- `doc_id` — номер документа.

---

# 🧮 Определение RFM-показателей

Для каждого клиента рассчитаны:

- количество покупок;
- общая сумма покупок;
- дата последней покупки;
- количество дней с последней покупки.

**Recency** рассчитывался относительно максимальной даты в наборе данных.

---

# 📊 Определение пороговых значений

Пороговые значения для RFM-сегментации определялись на основе распределения клиентских показателей.

В Excel были проанализированы:

- количество покупок;
- сумма покупок;
- количество дней с последней покупки.

Для показателей **R, F и M** использовались сводные таблицы и гистограммы.

На их основе были выбраны пороговые значения для последующей сегментации клиентов.

---

# 💻 SQL

В проекте разработаны SQL-запросы для:

### 1. Расчёта клиентских метрик

Получение:

- Frequency;
- Monetary;
- даты последней покупки;
- Recency.

### 2. Итогового RFM-анализа

На основании рассчитанных метрик каждому клиенту присваиваются:

- `R score`;
- `F score`;
- `M score`;
- итоговый `RFM segment`.

Всего формируется 27 комбинаций сегментов.

### 3. ABC-анализа

Клиенты ранжируются по выручке и распределяются на


группы:

- **A** — около 80% выручки;
- **B** — около 15% выручки;
- **C** — около 5% выручки.

---

# 📊 ABC-анализ

ABC-анализ использован для проверки гипотезы о том, что небольшая часть клиентов формирует значительную долю выручки.

### Результат

- **Группа A** — наиболее ценные клиенты, формирующие около 80% выручки.
- **Группа B** — клиенты со средней ценностью, около 15% выручки.
- **Группа C** — клиенты с низким вкладом, около 5% выручки.
