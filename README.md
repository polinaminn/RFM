> Учебный проект по сегментации клиентской базы с использованием **RFM-анализа** и **ABC-анализа**.

## 🎯 Цель проекта

Аптечная сеть располагает механизмом SMS-рассылок, но хочет использовать маркетинговый бюджет адресно.

Цель исследования — **классифицировать клиентов по покупательскому поведению и определить, какие предложения целесообразно направлять разным сегментам**.

## 🔎 Гипотезы

1. Разные группы клиентов требуют разного подхода.
2. Основная часть выручки формируется ограниченной группой наиболее активных клиентов.
3. Часть клиентов совершает только одну покупку и не возвращается.
4. Клиенты, которые давно не совершали покупок, имеют повышенный риск ухода и требуют отдельных мероприятий по возврату.

## 📈 Методология

Для каждого клиента рассчитаны три RFM-показателя:

| Метрика | Значение |
|---|---|
| **R — Recency** | Давность последней покупки |
| **F — Frequency** | Количество покупок |
| **M — Monetary** | Общая сумма покупок |

Для каждой метрики использована трёхуровневая оценка:

- `1` — хороший показатель;
- `2` — средний показатель;
- `3` — низкий показатель.

В результате формируется **27 возможных RFM-сегментов**.

Дополнительно проведён **ABC-анализ по выручке клиентов**.

## 🧹 Подготовка данных

Для идентификации клиента использовался номер бонусной карты.

Покупки без идентифицируемой бонусной карты исключались из клиентского RFM-анализа, поскольку их невозможно достоверно связать с конкретным клиентом.

Основные поля исходной таблицы:

- `datetime` — дата и время транзакции;
- `shop` — аптека;
- `card` — номер бонусной карты;
- `summ` — сумма чека;
- `summ_with_disc` — сумма чека с учётом скидок и списаний бонусов;
- `doc_id` — номер документа.

## 🧮 Определение пороговых значений

Пороговые значения R, F и M определялись на основе распределения клиентских показателей.

В Excel были проанализированы:

- количество покупок;
- сумма покупок;
- количество дней с последней покупки.

Для показателей **R, F и M** использовались сводные таблицы и гистограммы. На их основе были выбраны пороговые значения для последующей сегментации.

## 💻 SQL-анализ

В проекте разработаны запросы для:

1. расчёта клиентских метрик;
2. расчёта Recency, Frequency и Monetary;
3. присвоения RFM-оценок;
4. формирования итогового RFM-сегмента;
5. ABC-анализа клиентов по выручке;
6. агрегации результатов ABC-анализа.

📁 [SQL-запросы проекта](sql/)

## 📊 ABC-анализ

ABC-анализ использован для проверки гипотезы о вкладе разных групп клиентов в выручку.

По принятой в проекте классификации:

- **A** — около 80% выручки;
- **B** — около 15% выручки;
- **C** — около 5% выручки.

## 💡 Бизнес-выводы

### 🏆 Ценные клиенты

Для RFM-сегментов **111, 112, 121** предложены механики удержания:

- персональные бонусы;
- ранний доступ к акциям;
- программа постоянного клиента;
- дополнительные услуги.

Для этой группы не рекомендуется агрессивный маркетинг, поскольку клиенты уже лояльны.

### 🔄 Клиенты с единичными покупками

Для сегментов **131, 132, 133, 231** предложены:

- персональные предложения;
- бонусы за повторные покупки;
- напоминания о повторной покупке;
- программы накопления бонусов.

### ⚠️ Клиенты с риском ухода

Для сегментов **311, 321, 331, 332, 333** предложены:

- персональные скидки;
- бонусы за возвращение;
- предложения на основе предыдущих покупок.
